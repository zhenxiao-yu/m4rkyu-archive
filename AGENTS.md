Next.js rebuild in [zhenxiao-yu/M4rkyu.com](https://github.com/zhenxiao-yu/M4rkyu.com).

## Scope Rules

- Treat the repo as frozen. Only ship narrow fixes; no feature work.
- Do not change stack, build tooling, or runtime versions.
- Do not migrate the code to TypeScript, Next.js, or other modern stacks.
- Keep personal contact details and private data out of source, screenshots,
  fixtures, and generated content.
